# Security policy

Please report security vulnerabilities privately. Email **adit.dutta.work@gmail.com** with the subject `Genesis security report` and include the affected version, impact, and steps to reproduce. Please do not include API keys, private book content, or other sensitive personal data in a report.

Please avoid posting an unpatched vulnerability in a public issue. There is no formal response-time or bug-bounty commitment; reports will be reviewed as soon as practical.
